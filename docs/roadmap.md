# 后续规划

## 第一阶段：静态首页

- 保持首页作为全站入口。
- 控制首页信息密度，避免堆叠正文内容。
- 持续完善中英文切换体验。

## 第二阶段：栏目页

- 完善投资、技术、生活等二级页面。
- 每个栏目保持一致的列表结构。
- 投资栏目继续按标的维护状态、标签和投资逻辑。
- 技术栏目继续按知识点维护操作记录。

## 第三阶段：文章系统

- 建立更稳定的文章数据结构。
- 让二级页可以自动读取文章列表。
- 三级页用于展示完整文章或记录。
- 保持不引入复杂框架的前提下提升可维护性。

## 第四阶段：搜索

- 增加站内搜索入口。
- 优先支持标题、标签、正文关键词搜索。
- 初期可以使用静态索引，后续再考虑服务端搜索。

## 第五阶段：后台

- 增加更方便的内容录入方式。
- 后台应有基础鉴权。
- 管理功能只服务个人维护，不做公开注册系统。

## 第六阶段：数据库

- 逐步把留言、文章、标签等内容结构化保存。
- 现有留言服务继续使用 Cloudflare Worker + D1。
- 后续可评估是否把文章内容也迁移到 D1 或其它数据库。
