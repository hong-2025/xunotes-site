# 产品定位

`xunotes.com` 是一个面向个人长期使用的网站，当前定位为：

- 个人知识库
- 研究记录
- 笔记入口

它的核心目标不是展示复杂功能，而是把个人持续积累的内容放到一个稳定、清晰、可访问的位置。

## 当前内容方向

网站目前包含三个一级栏目：

- 投资：记录投资标的、状态、标签和投资逻辑。
- 技术：记录可复用的技术知识点和操作流程。
- 生活：作为美食、旅游、健康、其它内容的入口。

## 使用方式

首页承担导航入口作用。二级页面用于展示栏目内的条目。三级页面用于展示单个条目的详细内容。

## 内容原则

- 中文内容为主，英文内容跟随中文翻译。
- 内容以个人理解和观察为准，不追求过度包装。
- 投资内容仅为个人记录，不构成投资建议。
- 技术内容应便于日后快速复用。
